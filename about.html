About OCEANIC ORDER

A modern, real-time regatta tracking platform that brings the excitement of sailing competitions to your screen — live boat positions, race replays, and full leaderboard data.

Key Features

📍

Live GPS Tracking

Each boat is equipped with a GPS tracker that transmits its position in real-time. Watch boats move across the map with colored track trails.

🗺️

Interactive Map

Built on Leaflet.js with dark ocean tiles. Click any boat to see speed, heading, and coordinates. Toggle tracks, zoom in, and follow the fleet.

🔴

Real-Time Updates

Powered by Supabase Realtime, boat positions stream live via WebSocket. No page refresh needed — data arrives the moment a tracker sends it.

📊

Leaderboard

Dynamic rankings update as boats cross waypoints and finish lines. See speed, position, and ranking at a glance.

🔄

Race Replay

Browse past races and watch full replays with adjustable playback speed. Study race strategies and track performance over time.

📱

Responsive Design

Works on desktop, tablet, and mobile. The sidebar collapses into a slide-out panel on smaller screens for a seamless experience anywhere.

Technology Stack

Frontend
  • HTML5 / CSS3 / JavaScript — No framework dependencies, pure vanilla
  • Leaflet.js — Open-source interactive maps
  • CARTO Dark Tiles — Ocean-themed dark basemap
  • CSS Custom Properties — Theming and design tokens
  • Responsive Grid — Mobile-first layout system
Backend & Data
  • Supabase — PostgreSQL database + Realtime subscriptions
  • Supabase JS Client — Client-side data fetching
  • Row Level Security — Secure data access
  • WebSocket — Live position streaming
  • REST API — Historical data queries

Hardware Integration

GPS Tracker Setup Guide Available

To track real boats, you need GPS hardware on each vessel that sends coordinates to Supabase. We recommend the following components:

🔧

ESP32 Microcontroller

WiFi + Bluetooth capable microcontroller to process GPS data and send it to the cloud.

📡

NEO-6M GPS Module

Affordable, reliable GPS receiver that provides latitude, longitude, speed, and heading.

📶

SIM800L GSM Module

Cellular connectivity for sending GPS data when WiFi is not available on the water.

See the full GUIDE.md file included in this project for detailed wiring diagrams, Arduino code, and step-by-step hardware setup instructions.
